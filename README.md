# Lucky Star Friends — Forge 1.12.2

Неофициальный фанатский прототип мода с Конатой, Кагами, Цукасой и Миюки. В моде есть четыре мирных персонажа с отдельными блочными 3D-причёсками, пиксельными текстурами и анимацией ходьбы. Это не готовый большой мод с ИИ-чатом: сейчас их поведение построено на стандартных задачах Minecraft и простых правилах.

## Что уже работает

* Четыре яйца призыва в творческом инвентаре (в разделе «Разное»); персонажи сами по миру не появляются.
* ПКМ пустой рукой — приветствие или информация об отношениях. Все сообщения доступны на русском и английском (зависят от языка клиента).
* ПКМ цветком — знакомство и +5 дружбы; ПКМ тортом после знакомства — +10. Подарок расходуется вне творческого режима. Пауза между подарками — 10 секунд игрового времени; максимум — 100.
* Первый подаривший цветок становится лучшим другом конкретного персонажа. Прогресс и выбор друга сохраняются отдельно для каждого персонажа и переживают перезапуск мира. Другие игроки не могут забирать персонажа или управлять им.
* Shift + ПКМ пустой рукой — переключение между «следовать» и «ждать». Персонажи гуляют, смотрят на игроков, плавают и избегают враждебных мобов; в режиме ожидания они всё равно убегают от опасности. Следование работает в пределах 32 блоков в текущем измерении, без телепортации; если персонаж застрял или слишком далеко, вернитесь к нему.
* Три уровня текстовых реплик по уровню дружбы; сердечки при подарке.

Отношения здесь намеренно ограничены дружбой и невинной привязанностью: персонажи первоисточника — школьницы. Размножения, сексуального контента, брака, детей, семейной системы и свободного диалога с ИИ в этой версии нет.

## Сборка и запуск

Нужны **JDK 8**, доступ в интернет и около нескольких гигабайт свободного места для зависимостей ForgeGradle и Minecraft. Старый ForgeGradle не рассчитан на современные версии Java; перед запуском проверьте `java -version` и при необходимости укажите `JAVA_HOME` на JDK 8.

```sh
./gradlew build
```

В Windows: `gradlew.bat build`. Готовый файл будет в `build/libs/lucky-star-friends-0.1.0.jar`. Установите **Minecraft Java Edition 1.12.2** и **Minecraft Forge 1.12.2-14.23.5.2860**, поместите jar в папку `mods` и запустите профиль Forge. Для сетевой игры мод должен стоять и на сервере, и у всех клиентов. Для разработки можно использовать `./gradlew runClient`.

Генератор исходных текстур — `tools/generate_textures.py` (Python 3, без сторонних библиотек). Текстуры сделаны для проекта и не являются оригинальными ресурсами аниме.

Lucky Star и персонажи принадлежат соответствующим правообладателям; проект не является официальным.
