# Sigma Companions 0.3

Фан-мод для **Minecraft 1.21.1 / Fabric + Fabric API**: Коната Идзуми, Кагами Хиираги и Цукаса Хиираги из *Lucky Star* как спутницы для спокойного выживания и приключений.

**Статус:** alpha. Сборка, тесты и запуск выделенного сервера проверяются в CI; полноценная ручная проверка всех игровых ситуаций ещё не выполнена.

## Скачать

<https://github.com/s1gma-chan-sketch/sigma-chan-repesitory/releases/tag/v0.3.0-alpha.1>

Скачивайте `sigma-companions-0.3.0+mc1.21.1.jar`, а не архивы исходников.

## Установка

1. Установите **Fabric Loader 0.16.14+** для Minecraft **1.21.1**.
2. Положите **Fabric API** для 1.21.1 в папку `mods`.
3. Положите JAR мода в `mods`.
4. Запустите игру с Java 21.

Мод рассчитан и на клиент, и на выделенный сервер. Для меню и анимаций клиентская часть должна быть установлена у игрока.

## Что изменилось в 0.3

### Модели

- Чибби-риг заменён на **риг с пропорциями игрока**: голова 8×8×8, туловище/руки/ноги по 12 px высотой, общий рост около 2 блоков.
- Базовые UV-острова совместимы с раскладкой скина игрока 64×64; атлас 128×128 добавляет волосы, ленты, банты и предметы в руках.
- Коната: очень длинные синие волосы, ахогэ, зелёные глаза.
- Кагами: фиолетовые хвосты, тёмные ленты, более строгий взгляд.
- Цукаса: короткое каре, жёлтый бант, мягкие черты лица.
- Внешний слой головы/куртки/рукавов/штанов использует прозрачность, а не сплошной «шлем».
- Загруженные пользователем скины использованы как визуальный референс; их пиксели не встроены в мод. Текстуры и геометрия созданы процедурно для проекта.

### Диалог и поведение

- Локальный движок понимает простые команды владельца: «иди за мной», «подожди», «гуляй», «отметь дом».
- Отвечает на вопросы о крафте по небольшой базе рецептов Minecraft 1.21.1: факелы, хлеб, щит, кровать, сундук, печь и др.
- Считает целочисленные примеры безопасно: «сколько будет 17 * 3 + 5».
- «Что делать дальше?» учитывает здоровье, сытость, свет, факелы, еду, оружие и враждебных мобов рядом.
- Темы шахты, боя, фермы и строительства дают конкретные советы, а не только случайную реплику.
- Сохранены память «запомни …», продолжение темы, контекст мира и разные голоса персонажей.
- Внешний OpenAI/Anthropic остаётся опциональным; факты и команды по возможности обрабатываются локально.

### Взаимодействия

- Дружеские жесты: помахать, дать пять, обнять, погладить по голове, поддержать.
- Спутница подходит ближе перед жестом; есть анимация руки от первого лица.
- Перекус, вода и отдых: абстрактные потребности с задержкой эффекта и NBT-сохранением.

## Важные границы

Это **дружеский** фан-мод. Романтика, свидания, поцелуи, брак и размножение для Конаты, Кагами и Цукасы **не возвращаются**: это школьные персонажи, и утверждение «им 18» не используется как обход. Для романтических механик нужен отдельный, явно взрослый оригинальный состав.

Потребности после еды намеренно абстрактные: **сытость, вода, бодрость**. Туалетных, экскреторных и фетиш-механик нет.

*Lucky Star* принадлежит правообладателям; проект не является официальным продуктом. Извлечённые ассеты аниме/игр не используются.

## Управление

- **ПКМ** по спутнице — меню; еда в руке — угостить; любимый непищевой подарок — подарить.
- **G** по прицелу на спутницу — меню.
- **Shift+ПКМ** владельцем после уровня «Друзья» — следовать / ждать.
- `/sigma menu`, `/sigma status`, `/sigma talk <сообщение>`.
- `/sigma follow`, `/sigma stay`, `/sigma wander`, `/sigma home`.
- `/sigma wave`, `/sigma high_five`, `/sigma hug`, `/sigma pet`, `/sigma snack`, `/sigma drink`, `/sigma rest`.
- `/sigma summon konata|kagami|tsukasa` — требует уровень прав 2.
- `/sigma forget` — очищает краткую историю внешнего ИИ; явные воспоминания остаются в спутнице.

### Примеры сообщений

- `иди за мной`
- `подожди`
- `как сделать факелы?`
- `сколько будет 6 * 7?`
- `что делать дальше?`
- `где искать алмазы?`
- `запомни я люблю сады`

## Потребности

- Еда запускает анимацию перекуса; основной эффект приходит с задержкой (`digestionSeconds`, по умолчанию 90 секунд).
- После усвоения немного снижаются вода и бодрость — сигнал сделать привал.
- Вода восстанавливается рядом с источником; спутница может сама подойти к воде.
- Отдых восстанавливает бодрость; при низкой бодрости спутница может отдохнуть сама, если не следует за игроком.
- Значения сохраняются в NBT сущности.

## Внешний ИИ

По умолчанию работает **локальный диалог**: он не требует API-ключей и не отправляет текст наружу. Это не нейросеть, а детерминированный движок с контекстом, командами, рецептами и счётом.

Опционально владелец сервера может включить **OpenAI** или **Anthropic**:

```json
{
  "aiEnabled": true,
  "provider": "openai",
  "openaiModel": "gpt-5.4-mini",
  "anthropicModel": "claude-sonnet-4-6",
  "timeoutSeconds": 12,
  "requestsPerMinute": 6,
  "maxCompanionsPerPlayer": 8,
  "ambientDialogue": true,
  "digestionSeconds": 90
}
```

Файл: `config/sigma-companions.json` на сервере. Ключи читаются только из окружения сервера: `OPENAI_API_KEY` или `ANTHROPIC_API_KEY`. Клиентам ключи не передаются. Текст и игровой контекст уходят провайдеру только после явного разрешения игрока в меню. Возможна платная тарификация API. При ошибке/лимите используется локальная реплика.

## Крафт

- Приглашение Конаты: бумага + печенье.
- Приглашение Кагами: бумага + книга.
- Приглашение Цукасы: бумага + сахар.
- Шоколадный корнет: хлеб + какао-бобы + сахар, выход 2.

Старое кольцо обещания остаётся только как инертный legacy-предмет: рецепта и романтических действий нет.

## Миграция

- `akari` → Цукаса, `mio` → Кагами, `rei` → Коната.
- Доверие, подарки, явные воспоминания и дом сохраняются, где это возможно.
- Старые романтические флаги не загружаются и не используются.
- Старые приглашения продолжают работать и указывают на новый состав.
- Перед обновлением сделайте резервную копию мира.

## Проверка

CI собирает production JAR, запускает unit-тесты, проверяет ресурсы/UV/mixin/refmap и выполняет smoke-тест выделенного сервера:

- запуск Fabric 1.21.1;
- спавн Конаты;
- чтение NBT потребностей с задержкой;
- миграция старого профиля `mio` в Кагами;
- чистое завершение сервера.

Это **не** полная ручная проверка GUI, внешнего вида в игре, мультиплеера, долгой навигации и живых внешних AI-запросов.

## Сборка из исходников

```bash
./gradlew build
python3 tools/validate_resources.py
```

Требуется Java 21. Ассеты генерируются детерминированно:

```bash
python3 tools/generate_models.py
python3 tools/generate_assets.py      # нужна Pillow
python3 tools/preview_models.py       # нужна Pillow + NumPy, только для превью
```
