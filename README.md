# Sigma Companions

**Minecraft Java 1.21.1 · Fabric Loader · Fabric API · Java 21**

Игровая альфа `0.1.0`: оригинальные взрослые аниме-спутницы с собственными объёмными 3D-моделями, дружбой, согласованной романтикой, семейным союзом и подключаемым ИИ-диалогом.

> Это не порт персонажей Lucky Star. Коната, Кагами, Цукаса, Миюки, их модели и другие материалы оригинального аниме здесь не используются. Приписка «персонажам уже 18» не делает сексуализированный контент с узнаваемыми школьными персонажами допустимым. В этом проекте — только оригинальные взрослые героини и неоткровенное взаимодействие. Механики секса и размножения нет; семья реализуется через союз, доверие и общий дом.

## Что уже реализовано

- Три варианта внешности на собственной многосоставной Java-модели: голова, волосы, чёлка, лента, туловище, руки и ноги. Это **3D-модель**, а не плоская картинка; анимации ходьбы, ожидания, наклона головы, объятия, поддержки и короткого поцелуя.
- menu на **ПКМ** или **G** с русским интерфейсом: дружба, романтика, приключения, настройки.
- Разговоры, комплименты, подарки из руки; любимые подарки повышают доверие сильнее. Всем троим также нравятся торт и сладкие ягоды.
- Доверие **0–100**, отдельная история отношений для каждого игрока, сохранение в NBT мира вместе со спутницей.
- Объятия и поглаживание после достижения дружбы. Можно попросить спутницу поддержать и погладить игрока в ответ: анимация и регенерация I на 5 секунд.
- Явное включение романтической симпатии, свидания, поцелуи, церемония с кольцом, общий дом, возможность расстаться и сбросить согласие.
- Следование, ожидание, прогулка, возвращание к отмеченному дому ночью/в дождь, защита пригласившего игрока от монстров при доверии 35+.
- Крафты приглашений и кольца, творческая вкладка, команды для быстрого старта.
- Локальный диалог с распознаванием тем, игровым контекстом и явными воспоминаниями. Это сценарная система, **не нейросеть**.
- Дополнительные асинхронные диалоги через **OpenAI Responses API** или **Anthropic Messages API**. По умолчанию выключены.

## Быстрый старт

В тестовом мире с читами:

```mcfunction
/sigma summon akari
/sigma menu
/sigma talk Привет! Расскажи о себе
/sigma follow
/sigma stay
/sigma wander
/sigma home
```

- `akari`, `mio`, `rei` — доступные персонажи. `/sigma summon` требует уровень прав 2 и выполняется игроком.
- Подойди к спутнице на расстояние не более 6 блоков. `G` открывает меню только при наведении на неё; ПКМ работает непосредственно по сущности.
- `/sigma at @e[type=sigma_companions:companion,limit=1,sort=nearest]` — открыть меню выбранной сущности.
- **Shift + ПКМ** — переключить следование/ожидание после достижения дружбы.
- Возьми мак, книгу, редстоун, торт или ягоды в основную руку и нажми ПКМ по спутнице — подарок передастся. Лимит: **3 подарка за игровой день** на пару игрок–спутница.
- В выживании приглашения крафтятся из бумаги, любимого предмета и золотого самородка. Используй приглашение на твёрдом блоке. Кольцо: четыре золотых слитка вокруг аметистового осколка.

### Отношения

| Возможность | Доверие / условие |
|---|---|
| Знакомство, разговоры, подарки | Сразу |
| Дружба, объятия, поглаживание, команды движения | 15 |
| Поддержка игрока, общий дом, защита | 35 |
| Романтическая симпатия | Отдельное явное включение |
| Свидание, поцелуй | 55, симпатия, начатые отношения |
| Семейный союз | 80, свидание, симпатия, кольцо в руке |

«Симпатия» — игровая модель взаимности персонажа, а не согласие реального человека. Её можно отключить; свидание прекратится. «Расстаться» завершает союз и сбрасывает согласие. Чужой игрок не может менять режимы или романтический союз вашей спутницы; дружеское общение доступно другим игрокам отдельно.

Дом — навигационная точка, **не защита территории и не приватное хранилище**. Спутницы могут получать урон от монстров и погибнуть. Сохраняются доверие, симпатия, союз, подарок дня, дом и до шести явно запрошенных воспоминаний. Временные кулдауны и краткая история HTTP-диалога после перезапуска не восстанавливаются.

## ИИ: ChatGPT/OpenAI или Claude/Anthropic

**ChatGPT — продукт OpenAI, Claude — продукт Anthropic. Это разные компании и разные API.** Мод не выдаёт один сервис за другой и не требует ключа для обычной игры.

В сборке настраиваемые значения по умолчанию: `gpt-5.4-mini` и `claude-sonnet-4-6`. Это проверяемые конфигурационные значения, а не обещание «всегда самой новой модели»: владелец сервера может заменить ID в конфиге на доступный его аккаунту.

1. Останови сервер/мир. Открой `config/sigma-companions.json`.
2. Для OpenAI:

```json
{
  "aiEnabled": true,
  "provider": "openai",
  "openaiModel": "gpt-5.4-mini",
  "anthropicModel": "claude-sonnet-4-6",
  "timeoutSeconds": 12,
  "requestsPerMinute": 6,
  "maxCompanionsPerPlayer": 8,
  "ambientDialogue": true
}
```

Для Anthropic поставь `"provider": "anthropic"` и при необходимости измени `anthropicModel`.

3. Задай **на сервере** переменную окружения `OPENAI_API_KEY` или `ANTHROPIC_API_KEY` до запуска JVM. Не помещай ключ в JSON, чат, код, репозиторий или клиентскую сборку. Способ запуска зависит от хостинга; используй его менеджер секретов.
4. Перезапусти сервер. В меню спутницы открой «Настройки» и отдельно разреши внешний ИИ. На одного игрока действует лимит запросов в минуту.
5. Напиши сообщение. При ошибке сети, отсутствии ключа, лимите или некорректном ответе используется локальная реплика с пометкой.

**Приватность и стоимость:** после разрешения провайдер получает текст сообщения, короткую историю диалога, явно сохранённые воспоминания и небольшой игровой контекст (имя/возраст персонажа, стадия отношений, биом, время суток). UUID и точные координаты не включаются в промпт. IP сервера виден сервису при HTTPS-запросе. Ключ и HTTP-запросы остаются на сервере. API может тарифицироваться; настройки не задают лимит денежных расходов на стороне аккаунта.

`запомни я люблю сады` — сохраняет короткое воспоминание даже в локальном режиме. `/sigma forget` удаляет краткую сетевую историю, но **не** явные воспоминания в NBT. История HTTP не записывается на диск; данные, уже отправленные провайдеру, регулируются его политикой. Для OpenAI передаётся `store: false`, но это не обещание отсутствия журналов безопасности провайдера.

ИИ не получает инструменты, консоль, команды, право менять доверие, выдавать предметы или включать согласие. Ответ ограничен по длине и выводится только как текст.

Документация API: <https://developers.openai.com/api/docs/guides/text>, <https://platform.claude.com/docs/en/api/messages>.

## Сборка и проверка

Нужны JDK **21** и интернет к Maven Fabric/Mojang на первом запуске. Gradle 8.10.2 загружается стандартным wrapper; отдельная установка Gradle не нужна.

```bash
./gradlew build
# Windows: gradlew.bat build
```

Результат: `build/libs/sigma-companions-0.1.0+mc1.21.1.jar`. Архив `-sources.jar` не устанавливается в игру.

```bash
./gradlew runClient     # тестовый клиент
./gradlew runServer     # сервер разработки; EULA нужно принять самостоятельно
python3 tools/validate_resources.py
python3 tools/server_smoke.py  # только disposable CI/тестовая папка: принимает EULA и меняет run/server.properties
```

`tools/generate_assets.py` воспроизводит оригинальные пиксельные текстуры; для редактирования генератора нужен Pillow. Сами PNG уже включены, для сборки мода Python/Pillow не нужны.

CI: компиляция Java 21, 18 модульных тестов, проверка ресурсов/UV, запуск настоящего выделенного сервера 1.21.1, создание спутницы и чтение её профиля из NBT, штатная остановка. [Успешная проверка сборки](https://github.com/s1gma-chan-sketch/sigma-chan-repesitory/actions/runs/42426353924). **Это не полный автоматический прогон игровых сценариев:** ручной проверки заслуживают навигация в сложном рельефе, отображение меню на разных разрешениях, многопользовательские сценарии и длительная игра. Проект обозначен как альфа, а не как готовый коммерческий релиз.
