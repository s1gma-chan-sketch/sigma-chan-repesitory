# Sigma Companions 0.2

Фан-мод для **Minecraft 1.21.1 / Fabric + Fabric API**: Коната Идзуми, Кагами Хиираги и Цукаса Хиираги из *Lucky Star* как спутницы для спокойного выживания и приключений.

**Статус:** alpha. Мод проверяется автосборкой, тестами и запуском выделенного сервера, но полноценная ручная проверка всех игровых ситуаций ещё не выполнена.

## Скачать

Готовый JAR публикуется в релизах:

<https://github.com/s1gma-chan-sketch/sigma-chan-repesitory/releases/tag/v0.2.0-alpha.1>

Скачивайте файл `sigma-companions-0.2.0+mc1.21.1.jar`, а не архивы исходников.

## Установка

1. Установите **Fabric Loader 0.16.14+** для Minecraft **1.21.1**.
2. Положите **Fabric API** для 1.21.1 в папку `mods`.
3. Положите JAR мода в `mods`.
4. Запустите игру с Java 21.

Мод рассчитан и на клиент, и на выделенный сервер. Для меню и анимаций клиентская часть должна быть установлена у игрока.

## Что нового относительно 0.1

- Вместо оригинальных одинаковых персонажей — **Коната, Кагами и Цукаса**.
- У каждой свой силуэт: длинные волосы и ахогэ Конаты, хвосты и ленты Кагами, короткая стрижка и бант Цукасы.
- Отдельные пиксельные текстуры 256×256 и узнаваемые цвета.
- Дружелюбные жесты: помахать, дать пять, обнять, погладить по голове, поддержать.
- Спутница сначала подходит ближе, затем проигрывает анимацию; у взаимодействующего игрока есть короткая анимация руки от первого лица.
- Перекус, вода и отдых: абстрактные потребности с задержкой эффекта и сохранением в NBT.
- Более осмысленный локальный диалог: темы, контекст мира, память, продолжение разговора и разные реплики персонажей.
- Шоколадный корнет как любимый перекус Конаты.
- Старые приглашения из alpha-миров мигрируют на новый состав.

## Важные границы

Это **дружеский** фан-мод. Романтика, свидания, поцелуи, брак и размножение для этого состава **отключены**. Персонажи — школьные персонажи *Lucky Star*; мод не использует «повзросление» как обход ограничений.

Потребности после еды намеренно абстрактные: **сытость, вода, бодрость**. Туалетных,экскреторных и фетиш-механик нет.

Текстуры и модели — оригинальная пиксельная фан-графика, созданная для мода. Извлечённые ассеты аниме/игр не используются. *Lucky Star* принадлежит правообладателям; проект не является официальным продуктом.

## Управление

- **ПКМ** по спутнице — меню. Если в руке еда — угостить; если любимый непищевой подарок — подарить.
- **G** по прицелу на спутницу — меню.
- **Shift+ПКМ** владельцем после уровня «Друзья» — следовать / ждать.
- `/sigma menu`, `/sigma status`, `/sigma talk <сообщение>`.
- `/sigma follow`, `/sigma stay`, `/sigma wander`, `/sigma home`.
- `/sigma wave`, `/sigma high_five`, `/sigma hug`, `/sigma pet`, `/sigma snack`, `/sigma drink`, `/sigma rest`.
- `/sigma summon konata|kagami|tsukasa` — требует уровень прав 2.
- `/sigma forget` — очищает краткую историю внешнего ИИ; явные воспоминания «запомни …» остаются в спутнице.

### Меню

- **Дружба:** жесты, подарки, быстрые темы разговора.
- **Перекус:** угостить едой из руки, напоить водой рядом, отдых; полоски сытости/воды/бодрости.
- **Приключение:** следовать, ждать, гулять, отметить дом.
- **ИИ:** разрешение на внешний текстовый диалог.

## Потребности

- Еда запускает анимацию перекуса. Основной эффект приходит с задержкой (`digestionSeconds`, по умолчанию 90 секунд).
- После усвоения немного снижаются вода и бодрость — это сигнал сделать привал, а не туалетная механика.
- Вода восстанавливается рядом с источником воды; спутница может сама подойти к воде, если хочет пить.
- Отдых восстанавливает бодрость; при низкой бодрости спутница может отдохнуть сама, если не следует за игроком.
- Значения сохраняются в NBT сущности.

## Диалог и внешний ИИ

По умолчанию работает **локальный диалог**: он не требует API-ключей и не отправляет текст наружу. Это не нейросеть, а тематический движок с контекстом и памятью.

Опционально владелец сервера может включить **OpenAI** или **Anthropic** отдельно:

```json
{
  "aiEnabled": true,
  "provider": "openai",
  "openaiModel": "gpt-5.4-mini",
  "anthropicModel": "claude-sonnet-4-6",
  "timeoutSeconds": 12,
  "requestsPerMinute": 6,
  "maxCompanionsPerPlayer": 8,
  "ambientDialogue": true,
  "digestionSeconds": 90
}
```

Файл: `config/sigma-companions.json` на сервере.

Ключи читаются только из окружения сервера:

- `OPENAI_API_KEY`
- `ANTHROPIC_API_KEY`

Клиентам ключи не передаются. Текст и игровой контекст уходят провайдеру только после явного разрешения игрока в меню. Возможна платная тарификация API. При ошибке/лимите используется локальная реплика.

## Крафт

- Приглашение Конаты: бумага + печенье.
- Приглашение Кагами: бумага + книга.
- Приглашение Цукасы: бумага + сахар.
- Шоколадный корнет: хлеб + какао-бобы + сахар, выход 2.

Старое кольцо обещания остаётся только как инертный предмет для совместимости старых инвентарів: рецепта и романтических действий нет.

## Миграция с 0.1

- `akari` → Цукаса, `mio` → Кагами, `rei` → Коната.
- Доверие, подарки, явные воспоминания и дом сохраняются, где это возможно.
- Старые романтические флаги не загружаются и не используются.
- Старые приглашения продолжают работать и указывают на новый состав.
- Перед обновлением сделайте резервную копию мира.

## Проверка

CI собирает production JAR, запускает unit-тесты, проверяет ресурсы/UV/mixin/refmap и выполняет smoke-тест выделенного сервера:

- запуск Fabric 1.21.1;
- спавн Конаты;
- чтение NBT потребностей с задержкой;
- миграция старого профиля `mio` в Кагами;
- чистое завершение сервера.

Это **не** полная ручная проверка GUI, внешнего вида в игре, мультиплеера, долгой навигации и живых внешних AI-запросов. Сообщайте о проблемах с версией мода, логами и шагами воспроизведения.

## Сборка из исходников

```bash
./gradlew build
python3 tools/validate_resources.py
```

Требуется Java 21. Ассеты генерируются детерминированно:

```bash
python3 tools/generate_models.py
python3 tools/generate_assets.py  # нужна Pillow только для разработки
```
